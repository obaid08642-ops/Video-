# Playbook — lessons from Episode 04 and Episode 07 (use for every new episode)

## Structure
1. **Cold-open hook (1.5–3 s):** start with the *result* of the gag (reaction + funny image), then a "10 minutes earlier..." card (text added in editing).
2. **One gag per episode.** Not 4–5 plot turns. 18–28 s total is fine.
3. **Ending = payoff, then loop.** Last frame connects to the hook (door knob / raised hand).
4. **Beat order must be physically logical:** asleep → being stickered → someone laughs → wakes → sits up → stands → discovers → reacts → doorbell. Never skip the wake-up/standing steps.
5. **Close-ups and reaction faces** carry the comedy. Wide shots only to establish.
6. **Parent/couple/child dynamics** (the "triangle") outperformed solo-toddler antics in the reference videos' send ratios.

## Working with Meta AI (what actually worked)
- Generate **images first** (design bible, master image, per-shot keyframes), then image-to-video per shot.
- **One shot = one action**, 3–5 s needed. Meta returns 10 s: we cut the best 1.5–3.5 s.
- **Never chain** clips by last frame (identity drifts). Always start from a keyframe image.
- Dialogue **works** (Meta voices lines): max 2–4 words, one speaker per shot, quote the exact line. Meta sometimes adds unrequested lines: check with a transcript and trim.
- **Close-up/chest-up framing** keeps faces consistent; full-body shots give "bobblehead" proportions and face drift.
- Put the same stickers/props in **every first frame**; otherwise they appear mid-clip.
- Avoid mirrors (use the camera as the mirror), text on screen, many props, and extra characters (keep any guest back-of-head or one shot).
- Watch for later-frame drift in long clips (outfit change to jeans, new background clutter, sad/pained expressions). Only use the clean first seconds.
- Replace weak Meta sounds in editing (doorbell, music, SFX).
