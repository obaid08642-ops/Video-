# تحليل الفيديو المرجعي (قناة طبية مشابهة، #البشرة) — للاستلهام فقط، ممنوع النسخ
- مقاس 9:16، رسم 2D فلات بخطوط سوداء يدوية سميكة، خلفية بيج بملمس ورق، ألوان دافئة.
- جملة واحدة أعلى الشاشة في كل مرة، خط عربي عريض، الكلمة المفتاحية ملونة لحظة نطقها.
- الصوت: عامية مصرية سريعة، وقفات قصيرة كل 1 إلى 1.5 ثانية متزامنة مع تغيير الجملة.
- تغيير بصري كل ثانية تقريباً، وحركة كاميرا مستمرة (دوران بطيء، تكبير).
- "أيقونات الذاكرة": كل معلومة (تقويم يعدّ الأسابيع، قفل للحلقة المفتوحة) تظهر كبيرة ثم تصغر وتستقر في الركن.
- حلقة مفتوحة صريحة: "وفي الآخر… هخليك تعرف الغلطة" + قفل يفضل في الركن.
- انتقال zoom لجوه العنصر للدخول في الشرح ("تعالى ندخل جوه...").
- علامة X حمرا بتترسم على الحل الغلط.
