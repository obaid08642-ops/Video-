# جرثومة المعدة: نسخة التسجيل (v3): كلام كامل + علامات إلقاء + 8 شورتس + 3 بدائل لكل هوك
**للمراجعة الطبية أولًا، وبعدين التسجيل.** مفيش جرعات ولا ماركات ولا أسماء أدوية.

## علامات الإلقاء
- `//` وقفة قصيرة · `///` وقفة طويلة (تقريبًا نص ثانية)
- **كلمة بخط عريض** = شدّد عليها
- ↘ نزّل صوتك آخر الجملة (ثقة) · ↗ ارفع (سؤال/تشويق)
- [سريع] [بطيء] [بهمس] = غيّر السرعة أو الشدة
- **مهم:** أول جملة في أي فيديو بسرعة ومن غير «طيب» أو «خلينا». وكلم الكاميرا كأنك بتحكي سر لصاحبك.

## ترتيب التسجيل المقترح (عشان تتعب أقل)
1. **الهوكات الأول:** كل هوك من الـ8 شورتس، 3 مرات (البدائل A/B/C تحت). حوالي 6 دقايق.
2. الـ8 شورتس بالكامل (جسم الشورت بعد الهوك). حوالي 6 دقايق.
3. الحلقة الطويلة. حوالي 9 دقايق.

# الجزء 1: الـ8 شورتس (كل واحد 25–40 ثانية)

## شورت 1: القصة
**على الشاشة (ضخم):** «دكتور شرب جرثومة!» ← «1984» ← «منظار» ← «شرب» ← «التهاب» ← «نوبل 2005»
**الهوك (سجّل الـ3):**
- A: دكتور شرب جرثومة **عمدًا**… // وخد عليها **جايزة نوبل**! ↗
- B: سنة 1984… // دكتور عمل حاجة **مجنونة**: // شرب كوباية فيها **جرثومة**! ↗
- C: تخيّل دكتور يشرب جرثومة **بإيده**… // عشان يثبت إن الدنيا كلها **غلطانة**! ↗
**الجسم:**
كان بيقول إن قرحة المعدة سببها **جرثومة**… // مش التوتر. ↘
محدش صدّقه. ///
فعمل **منظار** يتأكد إن معدته سليمة… // وبعدها **شرب** الجرثومة! ↗ ///
وخلال **أيام**… // التهبت معدته! ↘
واتعالج بمضاد حيوي. //
وبعد سنين… // خد **نوبل** في الطب. ↘ //
ابعتها لحد فاكر إن القرحة من **التوتر**.

## شورت 2: الداتا
**على الشاشة:** «نص العالم!» ← «44%» ← «70% في إفريقيا» ← «من غير أعراض»
**الهوك:**
- A: **نص** سكان العالم… // فيهم جرثومة في **معدتهم**! // ومش عارفين! ↗
- B: حوالي **4 مليار** إنسان… // عندهم جرثومة في المعدة! ↗
- C: ممكن تكون **إنت** منهم… // من غير ما تحس! ↗
**الجسم:**
الرقم؟ // حوالي **4 مليار ونص**. //
وفي الدول النامية النسبة أعلى… // وفي إفريقيا توصل لـ**70%**. ↘
والمفاجأة؟ // أغلبهم مبيحسّوش **بأي حاجة**. ///
يعني السؤال مش «عندي جرثومة ولا لأ؟»… //
السؤال: **«هل عندي مشكلة منها؟»** ↗

## شورت 3: تحليل الدم
**على الشاشة:** «تحليل الدم موجب؟» ← «أجسام مضادة» ← «ممكن موجب بعد العلاج!» ← «اسأل دكتورك»
**الهوك:**
- A: تحليل جرثومة المعدة **بالدم** طلع موجب؟ // **استنى!** ↗
- B: «موجب» مش معناها إنك **مصاب دلوقتي**! ↗
- C: ليه تحليل الدم ممكن يخدعك في الجرثومة؟ ↗
**الجسم:**
التحليل ده بيكشف **أجسام مضادة**… // يعني جسمك قابل الجرثومة **قبل كده**. ↘
وممكن يفضل «موجب» **حتى بعد ما تتعالج**! ///
فمش دايمًا بيقولك إنك **مصاب دلوقتي**. ↘
التحاليل الأدق للعدوى الحالية: // اختبار **النَّفَس**… // وتحليل **البراز**. ↘
واسأل دكتورك عن **الأنسب** لحالتك. //
وابعتها لحد جاله تحليل موجب.

## شورت 4: علامات الإنذار
**على الشاشة:** «5 علامات!» ← 1 «قيء بدم» · 2 «براز أسود» · 3 «نزول وزن» · 4 «صعوبة بلع» · 5 «قيء مستمر»
**الهوك:**
- A: وجع المعدة ده **مش دايمًا بسيط**! // لو حسيت بالـ**5 علامات** دول… // **متستناش**. ↘
- B: 5 علامات في وجع المعدة… // **ممنوع** تتجاهلها! ↗
- C: متعتبرش كل وجع معدة **عادي**! ↗
**الجسم:** [سريع في القايمة، بطيء في الآخر]
واحد: // قيء فيه **دم**. اتنين: // براز **أسود**. تلاتة: // نزول وزن من غير **سبب**. أربعة: // صعوبة في **البلع**. خمسة: // قيء **مستمر**. ///
لو واحدة منهم ظهرت… // روح للدكتور **فورًا**. ↘
ومتشخّصش نفسك بالأعراض.

## شورت 5: ليه 4 أدوية
**على الشاشة:** «4 مكونات» ← «14 يوم» ← «الجرثومة بتقاوم» ← «كمّل الكورس»
**الهوك:**
- A: ليه علاج جرثومة المعدة بقى **4 أدوية** مرة واحدة؟! ↗
- B: **الجرثومة اتعلمت تقاوم**… // وعشان كده العلاج اتغيّر! ↗
- C: العلاج بقى **أصعب** من زمان… // إيه اللي حصل؟ ↗
**الجسم:**
عشان الجرثومة بقت **بتقاوم**! ///
زمان العلاج كان أبسط. // إرشادات سنة **2024** بتفضّل خطة من **4 مكونات**… // لمدة **14 يوم**: ↘
دوا بيقلل **الحمض**… // ومادة بتحمي **المعدة**… // ومضادين **حيويين**. ↘
وبتنصح ما نستخدمش مضاد حيوي معين زي زمان… // إلا لو الفحص أثبت إنه **لسه شغّال**. ///
والأهم: // **كمّل** الكورس! // نص كورس ممكن يعمل جرثومة **أقوى**. ↘

## شورت 6: الأكل
**على الشاشة:** «عسل؟ زبادي؟ ثوم؟» ← «مفيش أكل يعالجها» ← «التوتر مش السبب»
**الهوك:**
- A: عسل… // زبادي… // ثوم… // بيقتلوا جرثومة المعدة؟ ↗
- B: الأكل ده **بيعالج** الجرثومة؟ ↗
- C: متضيعش وقتك في **الوصفات**! ↗
**الجسم:**
الحقيقة: // لحد دلوقتي مفيش أكل ولا عشب **أثبت** إنه بيعالجها لوحده. ↘
والأكل الحار والتوتر؟ // **مش** هما اللي بيعملوا القرحة. ///
بس ممكن **يزودوا** الحرقان. ↘
الأكل بيخفف الأعراض… // لكن العلاج بـ**التحليل** والدكتور.

## شورت 7: الخرافة القديمة
**على الشاشة:** «التوتر = قرحة؟» ✗ ← «الجرثومة» ← «غيّر العلاج»
**الهوك:**
- A: لسنين صدّقنا إن القرحة من **التوتر**… // وطلع **غلط**! ↗
- B: الأكل الحار بيعمل قرحة؟ // **لأ!** ↘
- C: معلومة عن المعدة… // الأطباء نفسهم كانوا **غلطانين** فيها! ↗
**الجسم:**
الاعتقاد القديم كان: // توتر وأكل حار… // يساوي قرحة. ///
وبعدين اتضح إن السبب الأساسي… // **جرثومة**! // ومعاها مسكنات معينة لو اتاخدت كتير. ↘
واتغيّر العلاج: // بقى بنعالج **الجرثومة** بالمضاد الحيوي… // مش بس نهدّي الحموضة. ↘

## شورت 8: العدوى والأطفال
**على الشاشة:** «معدية؟» ← «غسل الإيدين» ← «الأطفال: الدكتور يقرر»
**الهوك:**
- A: الجرثومة **معدية**؟ // وطفلك وجع بطنه… // يبقى جرثومة؟ ↗
- B: جرثومة المعدة بتنتقل **إزاي**؟ ↗
- C: وجع بطن طفلك… // مش دايمًا **جرثومة**! ↘
**الجسم:**
طريقة العدوى مش **محسومة**… // لكن غالبًا بالفم، // أو أكل ومية **ملوثين**، // وبتنتشر جوه **العيلة**. ↘
الحماية: // غسل **الإيدين**… // وأكل ومية **نضيفين**. ///
وعند الأطفال: // وجع البطن مش دايمًا جرثومة. //
والفحص والعلاج قراره عند **طبيب الأطفال**… // متعملش تحليل **عشوائي**. ↘

# الجزء 2: الحلقة الطويلة (حوالي 8:30)

## 1) الدخلة (0:00–1:10)
سنة 1984… // دكتور شاب في أستراليا. ///
عنده فكرة أغلب الأطباء وقتها **ما صدّقوهاش**. ↘
الفكرة؟ // إن قرحة المعدة سببها **جرثومة**… // مش التوتر، ومش الأكل الحار. ↘
محدش صدّقه. // فعمل حاجة **مجنونة**. ///
عمل **منظار** يتأكد إن معدته سليمة… // وبعدها **شرب** كوباية فيها الجرثومة! ↗ ///
وخلال **أيام**… // ظهرت عليه أعراض، // والتهاب في المعدة. ↘
وبعدها اتعالج بمضاد حيوي. // وبعد سنين، // خد جايزة **نوبل** في الطب. ↘ ///
القصة دي ليها معنى: // جرثومة المعدة **حقيقية**… // بس اللي الناس بتعمله معاها بيبقى **غلط** كتير. ↘
النهارده هقولك: // إزاي تتشخّص، // وإزاي تتعالج، // وإيه الخرافات اللي لازم تسيبها.

## 2) نص العالم (1:10–2:00)
حوالي **4 مليار ونص** إنسان عندهم الجرثومة دي… // يعني قريب من **نص** سكان العالم! ↗
والنسبة بتختلف: // أعلى في الدول النامية… // وفي إفريقيا تقديرات بتوصل لـ**70%**. ↘
والمفاجأة: // أغلبهم مبيحسّوش **بأي حاجة**. ///
يبقى السؤال مش «عندي جرثومة ولا لأ؟»… // السؤال: **«هل عندي مشكلة منها؟»** ↗

## 3) الأعراض: مش دليل (2:00–3:00)
ممكن تحس بحرقان، // أو ألم في أعلى البطن، // أو انتفاخ، // أو غثيان. ↘
بس الأعراض دي نفسها بتيجي من الحموضة، والقولون، وبعض المسكنات. //
يعني الأعراض لوحدها **مش دليل**! ///
لكن فيه علامات **متستناش** معاها: [بطيء]
قيء فيه **دم**… // أو براز **أسود**… // أو نزول وزن من غير سبب… // أو صعوبة في البلع… // أو قيء مستمر. ↘
دي علامات تروح بيها للدكتور **فورًا**.

## 4) التحليل: الفخ (3:00–4:30)
نيجي لأكتر حاجة بتلخبط الناس: // **تحليل الدم**. ↗
بيكشف **أجسام مضادة**… // يعني إن جسمك قابل الجرثومة **قبل كده**. ↘
وممكن يفضل «موجب» **حتى بعد ما تتعالج**! // فمش دايمًا بيقولك إنك مصاب **دلوقتي**. ↘ ///
التحاليل الأدق للعدوى الحالية: // اختبار **النَّفَس**، // وتحليل **البراز**، // والمنظار مع عينة. ↘
وقبل أي تحليل: // قول للدكتور إنت بتاخد إيه من أدوية… // لأن أدوية الحموضة والمضادات الحيوية ممكن تغيّر **النتيجة**. //
ومتوقفش دوا من نفسك. ↘

## 5) العلاج: ليه 4 مش واحد؟ (4:30–6:15)
زمان العلاج كان أبسط. // دلوقتي الجرثومة بقت **بتقاوم**. ↘
إرشادات الجمعية الأمريكية لأمراض الجهاز الهضمي سنة **2024** بتفضّل خطة **رباعية**: ↗
دوا بيقلل حمض المعدة، // ومادة بتحمي، // ومضادين حيويين… // مع بعض لمدة **14 يوم**. ↘
وبتنصح ما نستخدمش مضاد حيوي معروف كان شائع زمان… // إلا لو الفحص أثبت إن الجرثومة **لسه حساسة** له. ↘
والخطة بتختلف حسب بلدك وحالتك… // والدكتور هو اللي **يحددها**. ///
أهم حاجة: // **كمّل** الكورس! // نص كورس ممكن يعمل جرثومة **أقوى**. ↘
وبعد العلاج لازم تحليل تاني بعد أسابيع… // عشان تتأكد إنها **راحت**.

## 6) الأكل والأعشاب: الخرافات (6:15–7:15)
هل فيه أكلة بتقتل الجرثومة؟ // عسل؟ // زبادي؟ // ثوم؟ // أعشاب؟ ↗
لحد دلوقتي مفيش أكل ولا عشب **أثبت** إنه بيعالجها لوحده. ↘ ///
والأكل الحار والتوتر؟ // ده كان الاعتقاد القديم لسنين… // والحقيقة إنهم **مش** السبب، // بس ممكن يزودوا الحرقان. ↘
الأكل بيخفف الأعراض… // لكن العلاج بيتحدد بالتحليل والدكتور.

## 7) معدية؟ والأطفال؟ (7:15–8:00)
طريقة العدوى مش محسومة تمامًا… // لكن غالبًا بالفم، // أو أكل ومية ملوثين، // وبتنتشر جوه العيلة. ↘
الحماية: // غسل الإيدين، // وأكل ومية نضيفين. ///
وعند الأطفال: // وجع البطن مش دايمًا جرثومة. // والفحص والعلاج قراره عند طبيب الأطفال. ↘

## 8) الخلاصة (8:00–8:30)
تلات حاجات: ↗
أولًا: // اتأكد بالتحليل **الصح**. // ثانيًا: // **كمّل** العلاج. // وثالثًا: // اعمل تحليل **بعد** العلاج. ↘
قولّي في الكومنتات: // تحب الحلقة الجاية نتكلم عن إيه؟

## نقاط لازم دكتور يراجعها قبل التسجيل
1. تحليل الدم ودقته وجملة «ممكن يفضل موجب بعد العلاج».
2. مدة التحليل بعد العلاج («بعد أسابيع»).
3. علامات الإنذار الخمسة.
4. وصف العلاج الرباعي بدون أسماء. وهل يتشال خالص لو شايف إنه يشجّع العلاج الذاتي؟
5. «ومعاها مسكنات معينة» في شورت 7.
6. معلومات الأطفال والعدوى.
7. «4 مليار ونص» و«70% في إفريقيا»: أرقام عالمية (مش مصر).
8. ما قلناش «سرطان» في أي هوك أو عنوان.
