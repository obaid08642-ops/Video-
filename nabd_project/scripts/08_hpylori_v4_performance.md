# جرثومة المعدة: نسخة الأداء (v4): كل جملة قبلها توجيه إلقاء
**للتسجيل. التوجيهات بين القوسين ما بتتقالش، دي تعليمات لصوتك بس.**

## 1) قواعد الاسم (ردي على سؤالك)
- **أول ذكر في أي فيديو (والهوك دايمًا): «جرثومة المعدة».** ده الاسم اللي الناس بتبحث بيه، وبيتكتب في الترجمة والعنوان فبيساعد الظهور.
- **بعدها: «الجرثومة»** من غير ما تقولها فاضية في الهوك. كلمة «الجرثومة» لوحدها في أول جملة مش واضحة لمشاهد جديد. في آخر الجسم أو أول شورت جديد، ارجع قول «جرثومة المعدة» تاني لأن كتير بيدخلوا من النص.
- **الاسم العلمي (هيليكوباكتر بايلوري):** مرة واحدة بس في الحلقة الطويلة، مش في الشورتس. ممكن يتكتب على الشاشة (H. pylori) وإنت ما تقولوش.
- **«الميكروب الحلزوني»:** مش هنستخدمه كاسم، لأنه مش اسم الناس بتبحث بيه، وممكن يلخبط. هنقول «شكلها لولبي» كمعلومة. (دي ممتعة: اسمها هيليكو = لولبي، باكتر = بكتيريا، بايلوري = البواب، فتحة المعدة السفلية.)

## 2) رموز التوجيه (قبل كل جملة)
- **الطاقة:** (حماس) · (عادي) · (هدوء) · (همس مشوّق)
- **السرعة:** (سريع) · (بطيء)
- **الصوت:** (أعلى) · (أوطى) · (أعمق/أتخن) · (أخف)
- **النبرة:** ↗ ارفع آخر الجملة (تشويق/سؤال) · ↘ نزّل (ثقة وحسم)
- **الوقفات:** `//` قصيرة · `///` طويلة (نص ثانية، قبل المفاجأة)
- **كلمة بخط عريض** = شدّد عليها
- **ابتسم** قبل الجمل المرحة، لأن الابتسامة بتتسمع في الصوت.
- مش لازم تلتزم بكل رمز حرفيًا. لو بتحس بجملة بطريقة تانية، سيبها، بس خلي التنوّع: ما تقولش 3 جمل ورا بعض بنفس الطاقة.

## 3) قواعد الحرية (ردي على سؤالك: أغيّر وأضيف وأشيل؟)
**تقدر تغيّر:** الألفاظ بلهجتك، ترتيب الجمل، تشيل جملة أو تضيف تشبيه أو قصة قصيرة، تعمل الجملة أقصر.
**ثوابت لو غيرتها ابعتلي أتأكد:**
1. **الأرقام:** 44%، 70% في إفريقيا، 14 يوم، 4 مكونات، 4 أسابيع.
2. **جمل الأمان 🔒:** «متوقفش دوا من نفسك»، «الدكتور هو اللي يقرر»، «كمّل الكورس».
3. **علامات الإنذار الخمسة.**
4. **تحليل الدم والتحاليل البديلة.**
5. **«الأطفال: القرار عند طبيب الأطفال».**
**لو أضفت معلومة جديدة:** ابعتهالي وأتأكد منها بنفس طريقة البحث.
**التسجيل هو المرجع:** أنا بعدين بطلّع الصورة والكابشن على اللي قلته فعلًا.

## 4) الهوكات (ردي على سؤالك: واحد ولا الكل؟)
- كل شورت له 3 هوكات (A/B/C). **تقدر تسجل واحد بس** (اللي عاجبك)، والباقي تتجاهله. جسم الشورت بيشتغل مع أي هوك.
- **رأيي:** سجّل الـ3 لو معاك 5 دقايق زيادة. ده بيديني اختيار أفضل حسب أداءك الفعلي (ساعات الهوك الأضعف على الورق بيطلع أقوى بصوتك). لكن مش لازم.
- لو اخترت واحد بس، اختاره **بالاعتماد على الإحساس بتاعك**، وابعتلي رقمه.

# الجزء 1: الشورتس (كل واحد 25–40 ثانية)

## شورت 1: القصة

- C: (استغراب · أعلى) تخيّل دكتور يشرب جرثومة المعدة **بإيده**… // عشان يثبت إن أغلب الأطباء **غلطانين**! ↗
**الجسم:**

- (هدوء · أوطى) أغلب الأطباء وقتها… // **ما صدّقوهوش**. ///
- (سريع · تصاعد) فعمل **منظار** يتأكد إن معدته سليمة… // وبعدها **شرب** الجرثومة! ↗ ///

## شورت 3: تحليل الدم
**على الشاشة:** «تحليل الدم موجب؟» ← «أجسام مضادة» ← «ممكن يفضل موجب لسنين» ← «اسأل دكتورك»

**الجسم:**

- (حماس · أعلى) وممكن يفضل «موجب» **لسنين**… حتى بعد ما تتعالج! ///
- (حسم) فمش دايمًا بيقولك إنك **مصاب دلوقتي**. ↘
- (سريع) التحاليل الأدق للعدوى الحالية: // اختبار **النَّفَس**… // وتحليل **البراز**. ↘
- (هدوء · 🔒) واسأل دكتورك عن **الأنسب** لحالتك. //
- (ابتسم) وابعتها لحد جاله تحليل موجب.

## شورت 4: علامات الإنذار
**على الشاشة:** «5 علامات!» ← 1 «قيء بدم» · 2 «براز أسود» · 3 «نزول وزن» · 4 «صعوبة بلع» · 5 «قيء مستمر»
**الهوك:**
- A: (جد · أعمق) وجع المعدة ده **مش دايمًا بسيط**! // لو حسيت بالـ**5 علامات** دول… // **متستناش**. ↘

**الجسم:**

## شورت 5: ليه 4 أدوية

- B: (همس مشوّق) جرثومة المعدة **اتعلمت تقاوم**… // وعشان كده العلاج اتغيّر! ↗
- C: (استغراب) العلاج بقى **أصعب** من زمان… // إيه اللي حصل؟ ↗

- (أوطى · جد) عشان الجرثومة بقت **بتقاوم** المضادات! ///

- (أعلى · حسم · 🔒) والأهم: // **كمّل** الكورس! // نص كورس ممكن يعمل جرثومة **أقوى**. ↘

## شورت 6: الأكل
**على الشاشة:** «عسل؟ زبادي؟ ثوم؟» ← «مفيش أكل يعالجها» ← «الحار والقهوة: مش السبب» ← «التدخين والملح: بيزودوا المشكلة»

- (حسم) واتغيّر العلاج: // بقى بنعالج **الجرثومة**… // مش بس نهدّي الحموضة. ↘

## شورت 8: العدوى والأطفال

# الجزء 2: الحلقة الطويلة (حوالي 8:30)

- (أعمق) بس الأعراض دي نفسها بتيجي من الحموضة، والقولون، وبعض المسكنات. //
- (حماس · أعلى) يعني الأعراض لوحدها **مش دليل**! ///
- (بطيء · جد · 🔒) لكن فيه علامات **متستناش** معاها: // قيء فيه **دم**… // أو براز **أسود**… // أو نزول وزن من غير سبب… // أو صعوبة في البلع… // أو قيء مستمر. ↘
- (أعمق) دي علامات تروح بيها للدكتور **فورًا**.

## 4) التحليل: الفخ (3:10–4:40)
- (فضول) نيجي لأكتر حاجة بتلخبط الناس: // **تحليل الدم**. ↗
- (عادي · أوطى) بيكشف **أجسام مضادة**… // يعني إن جسمك قابل الجرثومة **قبل كده**. ↘
- (حماس · أعلى) وممكن يفضل «موجب» **لسنين** حتى بعد ما تتعالج! // فمش دايمًا بيقولك إنك مصاب **دلوقتي**. ↘ ///
- (سريع) التحاليل الأدق للعدوى الحالية: // اختبار **النَّفَس**، // وتحليل **البراز**، // والمنظار مع عينة. ↘
- (عادي) وقبل أي تحليل: // قول للدكتور إنت بتاخد إيه من أدوية… // لأن أدوية الحموضة والمضادات الحيوية ممكن تغيّر **النتيجة**. //
- (هدوء · 🔒) وغالبًا الدكتور بيطلب وقف أدوية الحموضة حوالي **أسبوعين**… // والمضادات الحيوية حوالي **4 أسابيع** قبل التحليل. ↘
- (أعمق · 🔒) بس **هو** اللي يقرر… // متوقفش دوا من نفسك. ↘

## 5) العلاج: ليه 4 مش واحد؟ (4:40–6:20)
- (أوطى) زمان العلاج كان أبسط. // دلوقتي الجرثومة بقت **بتقاوم**. ↘
- (عادي · تشويق) إرشادات الجمعية الأمريكية لأمراض الجهاز الهضمي سنة **2024** بتفضّل خطة **رباعية**: ↗
- (سريع · تعداد) دوا بيقلل حمض المعدة، // ومادة بتحمي، // ومضادين حيويين… // مع بعض لمدة **14 يوم**. ↘
- (هدوء) وبتنصح ما نستخدمش مضاد حيوي معروف كان شائع زمان… // إلا لو الفحص أثبت إن الجرثومة **لسه حساسة** له. ↘
- (هدوء · 🔒) والخطة بتختلف حسب بلدك وحالتك… // والدكتور هو اللي **يحددها**. ///
- (أعلى · حسم · 🔒) أهم حاجة: // **كمّل** الكورس! // نص كورس ممكن يعمل جرثومة **أقوى**. ↘
- (عادي) وبعد العلاج لازم تحليل تاني بعد **4 أسابيع** على الأقل… // عشان تتأكد إنها **راحت**.

## 6) الأكل والتوتر: إيه الحقيقة؟ (6:20–7:35)
- (سريع · فضول) هل فيه أكلة بتقتل الجرثومة؟ // عسل؟ // زبادي؟ // ثوم؟ // أعشاب؟ ↗
- (هدوء · أعمق) لحد دلوقتي مفيش أكل ولا عشب **أثبت** إنه بيعالجها لوحده. ↘ ///
- (عادي) والأكل الحار والقهوة؟ // مش هما سبب القرحة… // بس ممكن يزودوا الأعراض. ↘
- (سريع · تعداد) لكن فيه حاجات **بتزوّد** المشكلة مع الجرثومة: // **التدخين**، // والمسكنات الكتير، // والملح الزيادة. ///
- (هدوء) والتوتر؟ // مش السبب الأساسي… // لكن دراسات بتقول إنه **عامل مساعد**. ↘
- (حماس) وليه ناس بتمرض بالجرثومة وناس لأ؟ // لأن **نوع** الجرثومة بيفرق، // وجسمك، // والعوامل دي. ↘
- (هدوء · 🔒) يعني الأكل والتوتر بيأثروا على **المعدة**… // لكن العلاج بيتحدد بالتحليل والدكتور.

## 7) معدية؟ والأطفال؟ (7:35–8:10)
- (عادي · بطيء) طريقة العدوى مش محسومة تمامًا… // لكن غالبًا بالفم، // أو أكل ومية ملوثين. ↘
- (سريع) الحماية: // غسل الإيدين، // وأكل ومية نضيفين. ///
- (هدوء · 🔒) وعند الأطفال: // وجع البطن مش دايمًا جرثومة. // والفحص والعلاج قراره عند طبيب الأطفال. ↘
