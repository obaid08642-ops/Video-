# الحلقة 7: نزلة البرد والأنفلونزا والكحة: نسخة الأداء (v2) للتسجيل
**التوجيهات بين القوسين ما بتتقالش، دي تعليمات لصوتك بس.** كل معلومة هنا اتراجعت (الجدول في `07_cold_flu_verification.md`). مفيش جرعات ولا أسماء تجارية ولا أسماء أدوية بعينها.

## 1) قواعد الاسم والكلمات
- **الهوك والعنوان:** استخدم الكلمة اللي الناس بتبحث بيها: «نزلة برد» (وفي الخليج «زكام»)، «أنفلونزا»، «كحة». قولها بالتناوب (نزلة برد / زكام) في الطويل عشان نلقط كل الدول.
- **«مضاد حيوي»** مش «أنتيبيوتك».
- **أسماء أدوية بعينها:** ما نقولهاش. بنقول «شراب الكحة» و«خافض الحرارة».
- **الأطفال:** في أي جملة فيها طفل، الجملة الأخيرة دايمًا «اسأل الدكتور أو الصيدلي». مفيش جرعة ولا عمر بدقة غير اللي مكتوب.

## 2) رموز التوجيه (زي حلقة 8)
(حماس) · (عادي) · (هدوء) · (همس مشوّق) · (سريع) · (بطيء) · (أعلى) · (أوطى) · (أعمق) · ↗ ارفع آخر الجملة · ↘ نزّل · `//` وقفة قصيرة · `///` طويلة · **عريض** = شدّد · 🔒 جملة أمان لازم تتقال زي ما هي · ابتسم قبل الجمل المرحة.

## 3) قواعد الحرية
**تقدر تغيّر:** الألفاظ بلهجتك، ترتيب الجمل، تشيل جملة، تضيف تشبيه أو قصة قصيرة.
**ثوابت لو غيرتها ابعتلي:** (1) 🔒 جمل الأمان. (2) تحت سنة: ما فيش عسل. (3) تحت سنتين: ما فيش شراب كحة ولا دوا برد. (4) مية الغسول: معقمة/مغلية ومبردة. (5) علامات الخطر. (6) «ما تديش أسبرين لطفل».
**لو أضفت معلومة جديدة:** ابعتهالي وأتأكد منها.
**أي كلمة غلط نطقها بتتقص:** ما تعيدش من الأول، كمّل.

## 4) الهوكات
كل شورت له 3 هوكات (A/B/C). سجّل اللي عاجبك أو الـ3 وأنا أختار الأقوى بصوتك.

# الجزء 1: الشورتس (10 شورتس، 25–40 ثانية)

## شورت 1: المضاد الحيوي والبرد
**على الشاشة:** «مضاد حيوي؟ ✗» ← «فيروس» ← «مفيش علاج للبرد»
**الهوك:**
- A: (همس مشوّق · أعلى) نزلة البرد… /// **مالهاش علاج**. // أيوه، صح سمعت! ↗
- B: (استغراب) كتبوا لك مضاد حيوي للبرد؟ // **استنى**… // ممكن يكون ملوش لازمة خالص! ↗
- C: (حماس) أغلب نزلات البرد سببها **فيروس**… // والمضاد الحيوي **ما بيقتلش الفيروس**! ↗
**الجسم:**
- (عادي) المضاد الحيوي بيشتغل على **البكتيريا**… // مش على الفيروسات. ↘
- (هدوء · 🔒) وعلاج نزلة البرد نفسها؟ // مفيش دوا بيشفيها… // الجسم بيتعافى لوحده، والعلاج بيخفف الأعراض بس. ↘
- (أعمق) والمضاد من غير داعي ممكن يسبب أعراض جانبية، // ويخلي البكتيريا **تقاوم** المضادات بعدين. ↘ ///
- (هدوء · 🔒) لو الدكتور شاف عدوى بكتيرية فعلًا، // هو اللي يكتب… // **بعد الفحص**. ↘
- (ابتسم) ابعتها لحد بيجري على الصيدلية أول ما يعطس.

## شورت 2: برد ولا أنفلونزا؟
**على الشاشة:** «بالتدريج = برد» ↔ «فجأة = أنفلونزا» ← «التحليل هو اللي يحسم»
**الهوك:**
- A: (حماس · سريع) برد ولا أنفلونزا؟ // في **3 فروق**… // وفي حاجة واحدة بس **بتحسم**! ↗
- B: (همس) أنفلونزا ولا برد؟ // اللي بيفرّق ممكن مش اللي إنت فاكره… ↗
- C: (عادي · أعلى) تعبان فجأة؟ // يمكن مش برد! ↗
**الجسم:**
- (عادي · سريع) البرد غالبًا بيبدأ **بالتدريج**: // رشح، عطس، وحلق بيوجع. ↘
- (أعلى) والأنفلونزا غالبًا **فجأة**: // سخونة، ووجع جسم شديد، وتعب كبير. ↗ ///
- (هدوء · 🔒) بس الأعراض بتتشابه كتير… // والتحليل هو الطريقة المؤكدة. ↘
- (عادي) وسخونة البرد غالبًا **قليلة أو مفيش**، // والأنفلونزا السخونة فيها **معروفة**. ↘
- (ابتسم) وفي الحالتين: راحة وسوائل.

## شورت 3: البلغم الأخضر والكحة اللي طولت
**على الشاشة:** «بلغم أخضر ≠ بكتيريا؟» ← «الكحة ممكن توصل 3 أسابيع»
**الهوك:**
- A: (همس مشوّق · بطيء) البلغم لونه **أخضر**؟ /// يعني لازم مضاد حيوي؟ ↗
- B: (حماس · أعلى) **لون** البلغم لوحده… // مش بيقولك محتاج مضاد ولا لأ! ↗
- C: (استغراب) كحتك لسه مكملة؟ // ممكن ده **طبيعي**… // بس لحد حد معين! ↗
**الجسم:**
- (عادي) لون البلغم بيتغير حتى مع الفيروسات… // فلونه **لوحده** مش دليل على بكتيريا. ↘
- (أعمق) وحتى لو الدكتور شاف بكتيريا، // مش كل حالة محتاجة مضاد. ↘ ///
- (هدوء) الكحة بعد البرد ممكن **تستمر لأسابيع**. // وغالبًا بتروح لوحدها لو أقل من **3 أسابيع**. ↘
- (أعمق · 🔒) لو عدّت **3 أسابيع**… // أو معاها دم، أو ضيق تنفس، أو سخونة بتزيد… // روح للدكتور. ↘

## شورت 4: العسل والكحة
**على الشاشة:** «🍯 فوق سنة ✓» ← «تحت سنة ✗ (خطر)»
**الهوك:**
- A: (همس مشوّق) عسل للكحة؟ /// بينفع… // بس **لناس مش كلهم**! ↗
- B: (حماس · سريع) في ناس **ممنوع** تاخد عسل خالص… // إنت منهم؟ ↗
- C: (استغراب) العسل **أنفع** من أدوية كتير؟ // الدراسات بتقول إيه؟ ↗
**الجسم:**
- (عادي) العسل ممكن يخفف الكحة عند الكبار والأطفال **فوق سنة**. // والأدلة محدودة ومتفاوتة. ↘
- (أعمق · بطيء · 🔒) لكن الرضّع **تحت سنة**… // مفيهمش عسل **خالص**. // لأنه ممكن يسبب تسمم خطير اسمه التسمم الوشيقي. ↘ ///
- (هدوء) واختار عسل **معقّم (مبستر)** لو هتديه لطفل. ↘
- (عادي · 🔒) ولو الطفل عنده ربو أو أعراض صعبة… // اسأل دكتور الأول. ↘

## شورت 5: شراب الكحة للأطفال
**على الشاشة:** «تحت سنتين: لأ» ← «اسأل الدكتور»
**الهوك:**
- A: (همس · أوطى) شراب الكحة اللي في بيتك… /// **خطر** على طفل صغير! ↗
- B: (استغراب) بتدي طفلك شراب كحة؟ // **استنى**! ↗
- C: (حماس) قبل أي شراب كحة لطفل… // اعرف **3 حاجات**! ↗
**الجسم:**
- (هدوء · 🔒) أي دوا كحة أو برد فيه مزيل احتقان أو مضاد هيستامين… // **ممنوع** للأطفال تحت **سنتين**. // ممكن يسبب آثار جانبية خطيرة. ↘ ///
- (عادي) وحتى بعد كده… // الأدلة إنها بتفيد الأطفال **ضعيفة**، // وكتير من الأدوية بتتكتب عليها «مش لتحت 4 سنين». ↘
- (أعمق · 🔒) فعشان كده: // أي دوا كحة أو برد لطفل… // **اسأل الدكتور أو الصيدلي الأول**. // ومتخلطش أكتر من دوا فيهم نفس المادة. ↘
- (ابتسم) وسوائل وراحة وعسل (**فوق سنة**) ساعات كفاية.

## شورت 6: فيتامين سي والزنك
**على الشاشة:** «🍊 مش بيمنع» ← «يقصّر شوية» ← «أدلة محدودة»
**الهوك:**
- A: (حماس) فيتامين سي بيمنع البرد؟ // **لأ**… // بس في حاجة تانية! ↗
- B: (همس) كل ما تتعب بتجري على فيتامين سي؟ // **اسمع** الأول! ↗
- C: (استغراب · أعلى) البرتقان بيحميك من البرد؟ // الدراسات رأيها **مختلف**! ↗
**الجسم:**
- (عادي · سريع) فيتامين سي بشكل **منتظم** مش بيقلل احتمال إنك تاخد برد عند أغلب الناس. ↘
- (أعمق) لكن لو بتاخده **بانتظام**، // ممكن يقصّر مدة البرد **شوية**: // حوالي 8% عند الكبار، و14% عند الأطفال. ↘ ///
- (هدوء) وإنك تبدأ تاخد جرعات كبيرة **بعد** ما تتعب… // مفيش تأثير ثابت. ↘
- (عادي) والزنك؟ // الأدلة **مختلف عليها**… // ومش مؤكد إنه بيقصّر. ↘
- (هدوء · 🔒) ولو بتاخد مكملات أو عندك مرض مزمن… // اسأل الدكتور. ↘

## شورت 7: النوم والبرد
**على الشاشة:** «6 ساعات أو أقل ← 4 أضعاف» ← «النوم = مناعة»
**الهوك:**
- A: (همس مشوّق · أعلى) لو بتنام **6 ساعات أو أقل**… /// احتمال تاخد برد **أكتر من 4 أضعاف**! ↗
- B: (حماس) مش فيتامين سي… // ولا الدوا… // في حاجة **أقوى** بتحميك من البرد! ↗
- C: (استغراب) ليه شغال طول الليل ودايمًا عيان؟ // العلم له رد! ↗
**الجسم:**
- (عادي) دراسة اتعرض فيها ناس لفيروس برد… // اللي نامو **6 ساعات أو أقل** كانوا أكتر عرضة **4 أضعاف** تقريبًا من اللي نامو أكتر من 7. ↘ ///
- (أعمق · بطيء) ودي علاقة… // مش بتثبت إن قلة النوم **هي** السبب لوحدها، // بس الدليل قوي بما فيه الكفاية. ↘
- (حماس) فنوم كويس + غسل إيدين: // أقوى من أي **وصفة سحرية**. ↗
- (ابتسم) ابعتها لصاحبك اللي بيسهر.

## شورت 8: غسول الأنف: مية الحنفية؟
**على الشاشة:** «مية الحنفية ✗» ← «معقمة/مغلية ومبردة ✓»
**الهوك:**
- A: (همس مشوّق · أوطى) غسول الأنف بينفع… /// بس **المية** اللي بتستخدمها ممكن **تقتل**! ↗
- B: (استغراب · أعلى) بتغسل أنفك بمية الحنفية؟ // **استنى**! ↗
- C: (حماس) غسول الأنف: // الطريقة الصح **من 3 خطوات**! ↗
**الجسم:**
- (عادي) غسول الأنف بمحلول ملحي بيخفف الاحتقان. ↘ ///
- (أعمق · بطيء · 🔒) لكن **ما تستخدمش مية الحنفية** مباشرة. // نادرًا جدًا، مية مش معقمة ممكن تحمل كائنات دقيقة خطيرة بتتسبب في عدوى قاتلة. ↘ ///
- (هدوء · 🔒) استخدم مية **معقمة أو مقطّرة**، أو مية الحنفية **المغلية والمبردة**. // وغيّر المحلول كل مرة. ↘
- (عادي) ونظّف الجهاز كويس وسيبه يجف. ↘
- (ابتسم · 🔒) ولو طفل صغير أو عندك مشكلة صحية… // اسأل الدكتور. ↘

## شورت 9: إمتى تروح للدكتور؟
**على الشاشة:** «⚠️ علامات الخطر» ← «كبار» ← «أطفال» ← «رضع تحت 3 شهور»
**الهوك:**
- A: (جد · أعمق) برد عادي… /// ولا **علامة خطر**؟ ↗
- B: (همس) لو شفت **العلامات دي**… // متستناش! ↗
- C: (حماس · أعلى) إمتى تبطل تعالج في البيت… // وتروح الدكتور **فورًا**؟ ↗
**الجسم:**
- (عادي · سريع · 🔒) للكبار: // ضيق في التنفس، // ألم أو ضغط في الصدر، // دوخة مستمرة، // تشوش، // أو تفاقم مرض مزمن. ↘ ///
- (أعمق) والأعراض اللي **تحسنت** وبعدين رجعت **أسوأ**… // ده علامة. ↘
- (هدوء · 🔒) للأطفال: // تنفس سريع أو صعب، // شفايف أو وش مزرق، // مش بيشرب، // نعسان جدًا أو مش بيتجاوب. ↘ ///
- (أعمق · بطيء · 🔒) والرضيع **تحت 3 شهور**: // أي سخونة… // **دكتور فورًا**. ↘

## شورت 10: الأسبرين والأطفال
**على الشاشة:** «أسبرين + طفل + برد ✗»
**الهوك:**
- A: (همس · أوطى) دوا موجود في كل بيت… /// **ممنوع** لطفل عنده برد! ↗
- B: (استغراب) خافض حرارة للطفل؟ // **مش أي حاجة**! ↗
- C: (حماس) قبل ما تدي طفلك أي دوا للحرارة… // اعرف **المنوع**! ↗
**الجسم:**
- (عادي · 🔒) **متديش أسبرين** لطفل أو مراهق عنده أنفلونزا أو برد أو جدري. // مرتبط بمتلازمة نادرة وخطيرة اسمها «راي». ↘ ///
- (هدوء) خافضات الحرارة الشائعة الأخرى ممكن تتاخد… // بس **بالجرعة اللي الدكتور أو الصيدلي يقولها** حسب وزن الطفل. ↘
- (أعمق · 🔒) ولو الطفل كان بيتحسن… // وفجأة بدأ **يترجّع كتير**، ويتعب… // روح **الطوارئ**. ↘

# الجزء 2: الفيديو الطويل (4–5 دقايق)
**الهوك الأقوى على الإطلاق، والباقي مرتب حسب سؤال الجمهور.**

## 1) الهوك والوعد (0:00–0:45)
- (همس مشوّق · بطيء · ميّل للمايك) نزلة البرد… /// **مالهاش علاج**. ↗ ///
- (عادي · أعلى) أيوه… // مفيش دوا في العالم بيشفي نزلة البرد. // الجسم هو اللي بيتعافى. ↘
- (حماس · سريع) طب إيه اللي بنشتريه من الصيدلية ده كله؟ // وهل المضاد الحيوي بيفيد؟ // وشراب الكحة؟ // وفيتامين سي؟ ↗
- (هدوء) النهارده هقولك إيه اللي **بينفع**… // وإيه اللي **تضيع** عليه فلوسك… // وإمتى **لازم** تروح للدكتور. ↘
- (أعمق) واستنى لآخر الحلقة… // في حاجة بتحميك من البرد **أكتر من أي دوا**. ↗

## 2) برد ولا أنفلونزا؟ (0:45–1:35)
- (عادي) نزلة البرد غالبًا بتبدأ **بالتدريج**: // رشح، وعطس، وحلق بيوجع. ↘
- (أعلى) والأنفلونزا غالبًا **فجأة**: // سخونة، ووجع جسم شديد، وتعب كبير. ↗
- (هدوء · 🔒) بس الأعراض بتتشابه… // والتحليل هو اللي بيأكد. ↘
- (عادي) والنزلة غالبًا بتخف لوحدها خلال حوالي أسبوع لعشرة أيام. // أما الكحة، فممكن تكمل أسابيع. ↘

## 3) المضاد الحيوي والفيروس (1:35–2:25)
- (عادي · بطيء) أغلب نزلات البرد والأنفلونزا سببها **فيروسات**. ↘
- (أعمق) والمضاد الحيوي بيشتغل على **البكتيريا** بس. ↘ ///
- (سريع) ولو اتاخد من غير داعي: // أعراض جانبية، // ومقاومة للمضادات. ↘
- (هدوء · 🔒) ولون البلغم الأخضر لوحده مش دليل. // لو الدكتور شاف عدوى بكتيرية بعد الفحص، هو اللي يكتب. ↘

## 4) إيه اللي بيريّحك فعلًا؟ (2:25–3:20)
- (عادي · سريع) راحة، // وسوائل كتير، // ومشروبات دافية. ↘
- (حماس) والنوم! // اللي بينام **6 ساعات أو أقل**… // احتمال البرد عنده **أكتر من 4 أضعاف**. ↗
- (عادي) غسول الأنف بمحلول ملحي بيخفف الاحتقان… // لكن بمية **معقمة أو مغلية ومبردة**. // **مش مية الحنفية مباشرة**. ↘
- (هدوء · 🔒) والعسل ممكن يخفف الكحة **فوق سنة**… // وتحت سنة: **ممنوع**. ↘

## 5) شراب الكحة وفيتامين سي والزنك (3:20–4:10)
- (عادي) معظم أشربة الكحة بتخفف الأعراض بس… // والأدلة إنها بتقصّر الكحة **ضعيفة**. ↘
- (أعمق · 🔒) وللأطفال: تحت **سنتين** ممنوع، // وفوق كده **اسأل الدكتور الأول**. ↘ ///
- (عادي) وفيتامين سي المنتظم مش بيمنع البرد، // بس ممكن يقصّره **شوية**. // والزنك: الأدلة **مختلف عليها**. ↘

## 6) إمتى تروح للدكتور؟ (4:10–4:50)
- (جد · أعمق · 🔒) للكبار: // ضيق في التنفس، // ألم في الصدر، // دوخة مستمرة، // تشوش. ↘ ///
- (هدوء · 🔒) وللأطفال: // تنفس سريع أو صعب، // شفايف زرقا، // مش بيشرب، // نعسان جدًا. ↘ //
- (أعمق · بطيء · 🔒) والرضيع **تحت 3 شهور**: أي سخونة… **دكتور فورًا**. ↘
- (هدوء) والكحة اللي عدّت **3 أسابيع**… روح للدكتور. ↘

## 7) الأسبرين والحماية (4:50–5:20)
- (أعمق · 🔒) **متديش أسبرين** لطفل أو مراهق عنده برد أو أنفلونزا. ↘
- (حماس) والحماية؟ // **غسل الإيدين** بانتظام // والنوم الكفاية. // وتطعيم الأنفلونزا **كل سنة** (لكل من فوق 6 شهور حسب توصية CDC). ↗

## ملاحظات مراجعة
- «مفيش علاج لنزلة البرد» = كلام CDC («no cure»). العلاج للأعراض فقط.
- 4 أضعاف: من دراسة (Cohen 2015, Sleep): 164 بالغ اتعرضوا لفيروس برد؛ ارتباط، مش إثبات سببية.
- 8% و14%: من مراجعة Cochrane لفيتامين سي (Hemilä & Chalker).
- «أسبوع لعشرة أيام» للبرد معلومة سريرية شائعة، **مش لقيت نص CDC بيقولها حرفيًا**؛ لو مش مرتاح قول «غالبًا بتخف لوحدها».
- «سنتين» FDA، و«4 سنين» تصنيف الشركات الطوعي. AAP: بإذن الدكتور بس (مصدر ثانوي).
- مفيش جرعات ولا أسماء تجارية ولا أسماء أدوية.
